# PPTX Viewer 1.0.0

View PowerPoint presentations in Chrome or Edge, with search and a full-screen slideshow. Files never leave your device.

## Highlights

- Opens `.pptx`, `.ppsx`, `.potx` and macro-enabled variants from a file picker, drag and drop, recent files, or (optionally) straight from downloads and right-clicked links.
- Slide list with thumbnails, fit-to-window zoom, light and dark themes.
- Search across slide text, tables and speaker notes (Ctrl+F).
- Slideshow with animation builds, transitions, speaker view, laser pointer, pen, slide grid and jump-to-slide.
- Copy a slide as an image or text, copy a whole-deck outline, print or save as PDF, export PNGs.
- Draws text with master and layout styles, shapes, pictures, tables, charts and SmartArt.

## Install

1. Download `pptx-viewer-1.0.0.zip` below and unzip it into a folder you will keep.
2. Open `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

Access to websites is optional and off until you turn it on in Settings. See [PRIVACY.md](../PRIVACY.md).
